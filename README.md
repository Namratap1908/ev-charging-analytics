# ⚡ EV Charging Stations Analytics

This data analytics project explores the growth and distribution of electric vehicle (EV) charging stations across the United States using public data. It combines Python-based analysis, interactive Tableau dashboards, and web-based Streamlit applications to uncover insights for sustainable transportation planning.

## Deployment

The EV Charging Station Analytics Dashboard has been successfully deployed on **Streamlit Cloud**. You can access the live application via the following link:

[EV Charging Station Analytics](https://ev-charging-analytics-mtn22hsuyvozbfqdwym69f.streamlit.app/)

The app showcases various metrics, including:
- The number of EV stations by state
- A filter for selecting charger types
- A correlation between EV station density and population data

This dashboard was created using **Streamlit** and is connected to a live dataset hosted on GitHub.
